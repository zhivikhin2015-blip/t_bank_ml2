# RL-дообучение GPT-2 для рекомендаций

- [**REPORT.md**](REPORT.md) — полная версия отчёта: постановка задачи, формулы и реализации кодом, реальные примеры, эксперименты, выводы, ограничения и воспроизведение.
- [**report_short.html**](report_short.html) — короткая удобная версия: основные результаты и выводы, компактные таблицы и кнопки навигации. Откройте локальный HTML-файл в браузере; интернет для просмотра не нужен.

Для быстрого знакомства начните с `report_short.html`. Для подробной оценки и повторения экспериментов используйте `REPORT.md`.

Код — `src/`, тесты — `tests/`, ноутбуки — `notebooks/`, данные — `data/`, фиксированные результаты — `results/`.

```text
├── REPORT.md                 Полный научный отчёт
├── report_short.html         Короткий интерактивный отчёт
├── src/
│   ├── legacy/               Исходная GPT-2, подготовка данных и базовые эксперименты
│   ├── research_v2/          Reward model, RL, оценка и диагностика
│   └── runtime/              Совместимый запуск, инференс и сборка отчёта
├── tests/                    Научные проверки и запуск unittest
├── notebooks/                Просмотр сохранённых результатов
├── configs/                  Протоколы и карта контрольных сумм
├── data/
│   ├── raw/                  Исходный Yambda
│   ├── processed/            Зафиксированные временные разбиения
│   └── features/             Производные признаки и их манифесты
├── results/
│   ├── baseline/             Первый эксперимент
│   └── research_v2/          Итоговый эксперимент: метрики, модели, журналы, манифесты
├── reports/figures/           Иллюстрации полного отчёта
├── docs/                     Воспроизведение и технические ограничения
└── scripts/reproduce.py      Проверка результатов и изолированный повтор
```

## Быстрый запуск

Python 3.12; зависимости зафиксированы в `requirements.txt`. При необходимости создайте окружение:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Проверка сохранённых файлов и научных инвариантов из корня репозитория:

```bash
.venv/bin/python -B scripts/reproduce.py verify
.venv/bin/python -B -m unittest discover -s tests -v
```

Полное повторное обучение выполняется отдельно от сохранённых результатов: [инструкции воспроизведения](docs/reproducibility.md). Крупные данные, веса моделей и рабочие кеши находятся локально и исключены из Git.

## Основной результат

На 432 новых пользователях того же временного периода RL по доле повысил ожидаемую модельную награду примерно на 0,616 п.п., со снижением NDCG@10 примерно на 2,66%. RL по суррогату времени дал около +2,25 с модельного суррогата при среднем изменении NDCG@10 около −0,26%. Это усреднение трёх обученных seed-моделей, а не измеренный эффект на реальных показах. Преимущество reward model над простым средним на новой когорте статистически не подтверждено.
