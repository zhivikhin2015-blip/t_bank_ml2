# Данные

- `raw/listens.parquet` — исходный Yambda-50M, фиксированная версия `dd6f3a19eef5866e346c3270e098baa641a44948`. SHA-256: `eed9cbd094af1e189507d2f8132a0dc9653b90e65480125c7cdccd601e0592d1`.
- `raw/dataset_info.json` — метаданные источника.
- `processed/baseline/` и `processed/research_v2/` — каталоги и временные разбиения первого и итогового экспериментов.
- `features/research_v2/` — производные признаки, оценки каталога и манифесты их входов.

Данные и признаки не коммитятся. Их происхождение, контрольные суммы и правила разбиения сохранены в протоколах и манифестах `results/`. Описание исходного набора — `docs/dataset.md`.

Новый запуск не использует окончательную выборку для подбора параметров. Известные границы переноса, отбор пользователей и неизвестные объекты описаны в `REPORT.md`.
