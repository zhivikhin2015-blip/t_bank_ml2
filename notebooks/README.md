# Ноутбуки

`results_review.ipynb` читает фиксированные JSON из `results/research_v2/` и отображает сохранённые графики. Он не обучает модели и не подбирает параметры на отложенной выборке. Откройте его в редакторе с поддержкой Jupyter и выберите окружение `.venv`.

Выводы ячеек не сохранены: ноутбук является инструментом просмотра, а численные первоисточники — файлы `results/`. Зависимости для самих расчётов перечислены в `requirements.txt`; поддержку интерфейса Jupyter предоставляет выбранный редактор.
