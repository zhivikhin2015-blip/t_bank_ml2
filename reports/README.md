# Отчёты по исследованию RL-рекомендаций

| Версия | Где открыть | Что внутри |
|---|---|---|
| **Компактный интерактивный отчёт** | [compact.html](compact.html) | Главные результаты и выводы, интерактивное сравнение 32 политик, влияние KL-регуляризации, пятишаговая генерация, ограничения исследования. |
| **Полный актуальный научный отчёт (v2)** | [research_v2/README.md](../research_v2/README.md) | Временной протокол, архитектуры, функции награды, таблицы, доверительные интервалы, диагностика, источники и инструкции воспроизведения. |
| Исходный отчёт (v1, историческая версия) | [README.md в корне проекта](../README.md) | Первоначальная работа до научного аудита и дополнительных экспериментов. Для актуальных выводов используйте v2. |
| Архив полного исследования | [research_v2_submission.zip](../output/research_v2/research_v2_submission.zip) | Код, сохранённые результаты, политики, графики и инструкции; архив сформирован до создания компактной HTML-версии. |

Откройте `compact.html` обычным браузером двойным щелчком. Это самостоятельный файл: данные, стили и графики встроены, интернет и установка библиотек не нужны. Ссылки на полную версию и исходные JSON работают при сохранении структуры проекта. Есть экспорт отображаемой таблицы в CSV и печатная версия.

HTML — представление завершённых экспериментов, а не новый запуск или интерактивный симулятор обучения. Переключатели показывают реально рассчитанные варианты; кривые между шагами соединяют измеренные точки. Исходные модели, численные артефакты и полный отчёт не изменены.

Источники чисел:

- [Итоговые сравнения и парные интервалы](../output/research_v2/summary.json).
- [Одношаговая оценка 32 политик и качество reward model](../output/research_v2/evaluations/holdout/results.json).
- [Пятишаговая оценка 17 политик](../output/research_v2/rollouts/holdout/results.json).
- [Технический benchmark](../output/research_v2/benchmark.json), [проверки исследования](../output/research_v2/scientific_checks.json).

Главная граница интерпретации: рост награды измерен замороженной reward model. Финальная выборка содержит новых пользователей того же периода; улучшение реальных откликов, удержания и переноса во времени не установлено.
