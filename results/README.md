# Зафиксированные результаты

`baseline/` содержит первый эксперимент, `research_v2/` — итоговый. Внутри каждого эксперимента:

- `summary.json`: основные сравнения;
- `diagnostics/`: качество reward model, затраты и диагностика поведения;
- `provenance/`: выбор моделей, протоколы доступа, контрольные суммы, проверки и журналы;
- `models/`: веса, состояния оптимизаторов и история обучения;
- `evaluations/` и `rollouts/`: результаты одношаговой и пятишаговой оценки;
- исходные документы и исторические материалы в `provenance/` необходимы для проверки происхождения результатов;
- `archives/`: точные архивы завершённых запусков; их внутренняя структура относится к моменту формирования.

Сохраняются только каталоги, существующие для данного эксперимента. Данные разбиений находятся в `data/processed/`, текущие иллюстрации — в `reports/figures/`. Старые пути `output/...` внутри зафиксированных манифестов — логические имена исходного запуска; их соответствие текущим файлам записано в `configs/reproduction_layout.json`.

Содержимое научных артефактов при упорядочивании не менялось. Проверка: `.venv/bin/python -B scripts/reproduce.py verify`. Новые запуски пишут в отдельную рабочую директорию, не в эти каталоги.

Основные таблицы: `research_v2/summary.json`, `research_v2/evaluations/holdout/results.json`, `research_v2/rollouts/holdout/results.json`. Данные и веса крупных бинарных файлов исключены из Git.
