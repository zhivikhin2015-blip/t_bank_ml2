# Исходный код экспериментов

- `legacy/` — подготовка Yambda, исходная GPT-2 и первое сравнение политик.
- `research_v2/` — временной протокол, reward model, REINFORCE, метрики и многошаговая оценка.
- `runtime/` — адаптер совместимости типов, технический инференс и окончательное оформление результатов.

Численный код сохранён побайтно: его контрольные суммы входят в замороженные протоколы. Прямой запуск из новых каталогов не используется, поскольку исходные проверки рассчитывают пути относительно исходной структуры эксперимента.

Запускайте этапы через `scripts/reproduce.py`: он создаёт изолированную рабочую копию исходной структуры. Это сохраняет действительность проверок хешей и не позволяет новому обучению перезаписать зафиксированные результаты. Карта расположения исходных файлов — `configs/reproduction_layout.json`; команды — в `docs/reproducibility.md`.
